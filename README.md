# 📌 Subscription Tracker

_A simple and efficient app to track your recurring subscriptions and expenses._

![Subscription Tracker](https://via.placeholder.com/800x400.png?text=Subscription+Tracker)

---

## 🚀 Features

✅ Add & manage subscriptions  
✅ Set renewal reminders  
✅ View total spending analytics  
✅ Categorize subscriptions  
✅ Secure authentication

---

## 🛠 Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
